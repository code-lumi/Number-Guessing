# 🎮 Number Guessing Game in Python

A simple and interactive Number Guessing Game developed using Python and Tkinter.

## 📌 About the Project

This project challenges the player to guess a randomly generated number between 1 and 50 within five attempts.

The game provides hints to help the player determine whether their guess is too high or too low.

## ✨ Features

- Random number generation.
- Interactive graphical user interface using Tkinter.
- Five chances to guess the correct number.
- Hints for incorrect guesses.
- Score and remaining chances display.
- Game-over notification.
- Play Again button to restart the game.

## 🛠️ Technologies Used

- Python
- Tkinter
- Random module

## ⚙️ Requirements

- Python 3 installed on your computer.
- Tkinter, which is included with many standard Python installations.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

   ```bash
   python number_guess_game.py
   ```

4. Enter a number between 1 and 50.
5. Click the CHECK button to submit your guess.
6. Use the hints to find the correct number.
7. Click PLAY AGAIN to start another game.
